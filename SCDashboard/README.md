Smart City Standards Dashboard
A Streamlit dashboard for browsing smart-city standards, comparing projects, reviewing maturity gaps, and inspecting supporting evidence.

Quick start on Windows
Install Python 3.12 and enable Add Python to PATH during installation.
Extract the project folder to a normal location such as Documents or Desktop.
Double-click run_dashboard.bat.
The first run creates .venv and installs the packages in requirements.txt.
Open the local address shown in the terminal, normally:
http://localhost:8501
Link to the dashboard
