Smart City Standards Intelligence Platform (KACST)
A Streamlit-based interactive intelligence platform designed for searching, analyzing, and comparing smart city standards, evaluating organizational maturity gaps, and reviewing supporting evidence.

Project Overview & Features (Point by Point)
This platform was developed in alignment with the national smart city standardization initiative led by KACST. Key features include:

Smart City Standards Repository & Browsing:

Centralized, searchable repository of national and international smart city standards (e.g., ISO, ITU, IEC, IEEE).
Multi-field filtering by domain, organization, maturity level, or target urban sector.
Project & Standard Comparison:

Side-by-side comparative analysis between different standards and implementation frameworks.
Cross-referencing technical requirements against existing smart city infrastructure.
Maturity Gap & Assessment Analysis:

Quantitative and qualitative evaluation of smart city project readiness.
Identification of missing standards, compliance risks, and technical gaps across target domains.
Supporting Evidence & Audit Trail:

Detailed evidence log linked to specific compliance items and standard guidelines.
Verification tools to inspect uploaded documents, benchmarks, and field evaluations.
Interactive Visualization & Data Export:

Real-time charts and KPI indicators built with Streamlit and modern Python analytical libraries.
Option to export filtered views and summary reports for decision-makers.

Quick Start (Windows)
Prerequisites: Install Python 3.12 (ensure you select "Add Python to PATH" during installation).
Setup: Extract the project folder to a convenient location (e.g., Documents or Desktop).
Run: Double-click run_dashboard.bat.
Note: The first run automatically creates a virtual environment (.venv) and installs required packages from requirements.txt.
Access: Open the address shown in your terminal (typically): http://localhost:8501
